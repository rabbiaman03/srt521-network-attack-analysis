# Instructions for the agents working here

Two coding agents work in this directory at the same time, one per terminal pane, each on its own task. Read this file before your first action. Keep your working directory at `lab01/`; write outputs only under the directories your brief names.

- `Start task N` from the user means: read `tasks/taskN.md` in full and carry it out to the end, in order. `Continue task N` means: read it again, check what is already done, and finish the rest without repeating completed stages or deleting mailbox messages.
- The task file names where to work, what to produce, how to run it, and which message to leave for the other agent in `mailbox/`. Ask for permission when your tool requires it. If task instructions are missing, report the missing information and stop rather than inventing requirements.
- The other agent's messages to you are files in `mailbox/`. Read them when the task file says to, and only then.
- Stay inside the directories the task file names. Never edit the other agent's directory, `specs/`, `check.py`, `access.log` or `firewall.log`, and never delete a mailbox file.
- Stop when the task file says the task is done. Do not start another task, do not commit, do not push.
